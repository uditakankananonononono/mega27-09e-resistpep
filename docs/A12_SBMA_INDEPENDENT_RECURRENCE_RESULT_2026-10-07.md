T_obs = 4 (AMP, gene) pairs with Tier A hits in >=3 same-AMP lines: CAP18:basS 4 lines (SNPs + insertion), LL37:lptC 3, LL37:wzzE 3, HBD3:basR 3 (SNPs). Locked rule (p<0.05): AMP-specific Tier A recurrence beyond length-weighted opportunity IS present outside the sbmA-deletion lines.
Deviation, disclosed: the first run (results/sbma_independent_a12_first_run_included_intergenic.json; T=6, p<1e-5) failed to implement the lock's exclusion of intergenic events and so counted yejK/yejL (one shared intergenic event pair, same lines) as two pairs. I caught it by inspecting contributors, fixed the script to the lock, and report the corrected run; both are kept. Also per the lock, 7 events whose gene names are not in the MG1655 name table (yejM, yciM, yebS, yebT, ybiH; old names for lapC/lapB/letA/letB-type genes) were excluded and are listed in the JSON; excluding them is conservative for T.
Limits: the null treats genes as independent draws weighted by CDS length, so it ignores hotspots, operon/linked genes, and mutation-rate heterogeneity; the p-value is an extreme-tail figure under that simple null and should not be read as a precise probability. LL37 lptC and wzzE both involve LL37_3 (same line). basS/basR are a two-component pair (PmrB/PmrA-type; basS = PmrB confirmed by A11 at 84.3% identity), so those two are one biological system, not independent. Lines within an AMP are not independent; strata are 4-5 lines. HBD3 and CAP18 hits are tied to specific AMPs, so this is within-AMP recurrence, not a pan-AMP mechanism.
Status for the 09d gate: this is a surviving orthogonal leg for a DESCRIPTIVE claim ("recurrent Tier A hits in LPS/two-component-system genes in lines without sbmA deletion, within-AMP"). It is not the sbmA/waaY candidate claim, is not mass-spec or PubMed evidence for a named peptide, and does not meet the 09d gate by itself.
