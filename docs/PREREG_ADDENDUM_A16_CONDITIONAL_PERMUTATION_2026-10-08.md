# A16 prereg (locked before any A16 computation) - observed-margin conditional permutation of A12 recurrence
Origin: ChatGPT judge round on the manuscript (docs/JUDGE_ROUND_MANUSCRIPT_2026-10-08.md) called the A12 length-weighted redraw null too naive. Judge output is advice; this design is mine and is fixed here.
Prior exposure (disclosed): the A12 dataset, its T=4 and contributing pairs, and the line-by-gene Tier A ledger were all seen before this lock (A5, A6, A12, A14). This is NOT a blind test; it conditions on structure already seen. The outcome of the permutation null itself has not been computed.
Data: exactly the A12 universe: the 20 non-S Spohn 2019 lines, mapped Tier A events (64 events; 7 unmapped-name events excluded as in A12), one event per distinct (line, gene), same code path as scripts/sbma_independent_a12.py (a6.tier, intergenic excluded). Lines/AMPs fixed by the data.
Statistic T: number of (AMP, unit) pairs with events in >= 3 distinct lines of the same AMP. Primary unit = gene (identical to A12 T; T_obs must reproduce 4, else the run is aborted and reported).
Null A (PRIMARY, one endpoint): binary 20-line x gene matrix with row sums (distinct genes per line) and column sums (distinct lines hit per gene, across all AMPs) held fixed. Sample uniformly-ish with the curveball algorithm: burn-in 5,000 trades, then 100,000 samples with 50 trades between samples, numpy default_rng seed 20261016. AMP labels stay attached to lines. p_A = (1 + #{T_null >= T_obs}) / (1 + 100,000). Also report the null mean, 95th, 99th percentile and the full T histogram.
Reading rule (fixed now): if p_A <= 0.01 (T_obs at or above the null 99th percentile) -> "within-AMP recurrence exceeds what the observed gene-frequency and line-burden margins produce". If 0.01 < p_A <= 0.05 -> "weakly exceeds, not at the 99th percentile". If p_A > 0.05 -> "the A12 pattern is explained by marginal recurrence structure" and this is reported as a result in the manuscript, not buried.
Sensitivity B (secondary, not a second endpoint): collapse genes to neighborhoods = maximal runs of consecutive CDS on the same strand with inter-gene gap <= 1,000 bp in the pinned MG1655 CDS table. A line counts once per neighborhood. Recompute T_B (pairs of AMP x neighborhood in >= 3 lines) on observed data and under the same curveball null on the neighborhood matrix, same seed and settings. Report T_B_obs and p_B. Reading: if T_B_obs falls below its own T_obs pairs (a pair merges) it is reported as is; no re-tuning of the 1,000 bp rule afterwards.
No threshold shopping: the >=3 line threshold, 1,000 bp rule, seeds and sample counts are final.
Limits locked in: margins preserved by the null include the recurrence itself (conservative, can erase a real signal); lines within an AMP are not independent; shared ancestry, hotspots and linkage are only partly addressed (B); no 09d gate is met by this analysis; the gate stays UNMET regardless of outcome. A negative outcome is a result and is published here and in the paper.
