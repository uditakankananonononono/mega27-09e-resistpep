# A13 prereg (locked before any A13 computation) - second-dataset check of within-AMP recurrence
Question: does the A12 statistic (within-AMP Tier A gene recurrence beyond length-weighted opportunity) also appear in an independent organism/dataset? Dataset: Blanco 2020 S. maltophilia D457 evolved lines (PR-39 8 lines, LL-37 8 lines; 16 lines; small variants only: SNPs and 1-23 nt indels, all Tier A by A6 definition). Bac7 2023 (3 strains, one AMP) cannot reach a >=3-line threshold on any gene except by all three strains, so it is declared NOT TESTABLE and excluded.
Universe for the null: the NCBI NC_017671.1 feature table (pinned data/raw/smaltophilia_D457_NC_017671.1_features.ft), CDS features only (4,324). Gene names map by gene name or old_locus_tag (SMD_nnnn, case-insensitive); unmapped records are excluded and listed.
Statistic T and null: identical to A12 - T = number of (AMP, gene) pairs with events in >=3 distinct same-AMP lines; per line, keep its number of distinct mapped genes and redraw distinct genes from the CDS universe weighted by CDS length; 100,000 replications, numpy default_rng seed 20261013. p = P(T_null >= T_obs).
Reading rule: p < 0.05 -> within-AMP recurrence beyond length-weighted opportunity is replicated in a second organism; else NOT replicated. Descriptive note regardless: the contributing pairs (genes will differ from E. coli; this tests the phenomenon of recurrence, not the same genes, and is not gene-level replication).
Prior exposure (disclosed): A4/A5 already report sspB 6/8 (PR-39) and mraW 3/8 (LL-37), so T_obs is known (expected 2) before this lock; only the null probability is new. Caveats locked in: the same simple null as A12 (ignores hotspots, operon/linkage, rate heterogeneity); Blanco lines may share ancestry, which would inflate recurrence relative to independent lines; 8 lines per AMP.
